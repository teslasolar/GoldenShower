# GoldenEye 007 - Dev History

## Timeline
- Nov 1994: Project greenlit
- Jan 1995: Dev starts
- Aug 1997: Release

## Origin
- Initially proposed as SNES 2D platformer
- Hollis pushed for N64 3D shooter
- First design doc: "similar to Virtua Cop"
- Early concept: on-rails + FPS hybrid modes

## Influences
- Virtua Cop (Sega, 1994)
- Doom (id Software, 1993)
- Super Mario 64

## Core Team
- **Martin Hollis**: Director, STAN system creator
- **Mark Edmonds**: Lead programmer, engine
- **Karl Hilton**: Background artist, levels
- **B. Jones**: Character artist
- **David Doak**: (face used for Dr. Doak NPC)

## Challenges
- N64 specs unknown at start
- Controller not finalized
- SGI Onyx slower than final N64 hardware
- Textures halved for performance

## Cut/Changed
- Realistic blood (Nintendo requested removal)
- Rumble Pak reload mechanic (scrapped)
- Dev faces used for enemy soldiers

## Results
- 8M+ copies sold
- Defined console FPS genre
- Multiplayer mode added late (almost cut)
