GOLDEN SHOWER

GoldenEye 007 Multiplayer Reconstruction

by Konomi Systems

ABOUT

A faithful browser-based reconstruction of the legendary GoldenEye 007 multiplayer experience. Built entirely with vanilla JavaScript, WebGL, and P2P networking.

No servers required - connect directly with friends using WebRTC or discover open games via WebTorrent.

P2P MULTIPLAYER

Direct peer-to-peer connections via KQTT protocol

CLASSIC WEAPONS

PP7, KF7 Soviet, Golden Gun & more

ARENA COMBAT

North, East, South, West dock areas

GLOBAL CHAT

Connect with players worldwide

PLAY NOW

CONTROLS

  • W A S D - Movement
  • Mouse - Look around
  • Left Click - Shoot
  • Space - Jump
  • 1-7 - Switch weapons
  • Enter - Open chat
  • Tab - Scoreboard
  • Q - Quick play (solo)

TECHNOLOGY

WebGL WebRTC WebTorrent KQTT P2P Markdown Docs UDT Modules GitHub Pages

HOW TO CONNECT

Option 1: Create a lobby and share the 6-character code with friends

Option 2: Use P2P connection panel to exchange WebRTC offers manually

Option 3: Enable WebTorrent for open P2P discovery via DHT
